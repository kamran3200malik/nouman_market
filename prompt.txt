# Beauty Salon & Makeup Artist Marketplace — Laravel + Vue.js

Build a complete, modern, responsive **Beauty Salon & Makeup Artist Marketplace** using:

* **Backend:** Laravel 12+
* **Frontend:** Vue 3
* **SPA:** Inertia.js
* **Database:** MySQL
* **Authentication:** Laravel Breeze/Sanctum as appropriate
* **Styling:** Tailwind CSS
* **Icons:** Lucide Icons
* **Permissions:** Spatie Laravel Permission
* **File Storage:** Laravel Storage
* **Queues/Notifications:** Laravel Queues + Notifications
* **Architecture:** Clean, modular, scalable Laravel architecture

The application should be production-ready, responsive, secure, easy to maintain, and have a polished modern beauty/salon UI.

* The architecture can support thousands of artists and customers.

Before implementing each feature, think about:

**"How would a real beauty salon customer use this?"**

and

**"How would a real makeup artist manage their business using this platform?"**

Build the application with those two perspectives in mind.

Start by designing the **database architecture, user roles, application flow, and folder structure**, then implement the project module by module. Do not skip validation, authorization, responsive design, loading states, empty states, error handling, and security.

This prompt is intentionally broad enough to create a **full salon marketplace**, rather than just a salon booking website. It also leaves room to later add **multiple salons, home services, online payments, commissions, subscriptions, packages, and mobile apps** without redesigning the core architecture.
